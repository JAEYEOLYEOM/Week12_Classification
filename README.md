# 12주차 강풍 분류 실습

## 실습 목적

풍속과 기상 데이터를 이용해 실제 풍속이 1시간 뒤 4.0 m/s 이상인지 분류하는 실습입니다.
학습용 기준 예측과 로지스틱 회귀 예측의 성능을 비교하고, 2024년 12월 1~7일의 실제 풍속과 강풍 판정을 시각화합니다.

## 파일 역할

| 파일 | 역할 |
|---|---|
| `wind_dataset.csv` | 예측 시각, 정답 시각, 풍속, 기온, 습도 및 과거 풍속 데이터가 들어 있는 원본 데이터 |
| `classify_wind.py` | 시간 검증, 학습·평가 데이터 분리, 기준 예측, 로지스틱 회귀 학습 및 평가 결과 생성 |
| `classification_predictions.csv` | 평가 744행의 실제 정답, 강풍 확률 및 예측값 |
| `classification_scores.csv` | 세 가지 기존 방법과 로지스틱 회귀 0.20 판정의 혼동행렬 및 평가 지표 |
| `plot_strong_wind.py` | 평가 예측 CSV를 읽어 12월 1~7일 강풍 그래프를 생성 |
| `strong_wind_december.png` | 실제 풍속과 강풍 판정 그래프 이미지 |
| `.gitignore` | Python 캐시와 컴파일 파일을 Git 추적에서 제외 |

## 필요한 패키지

그래프를 생성하려면 Matplotlib이 필요합니다.

```powershell
python -m pip install matplotlib
```

분류 스크립트는 기본 Python 라이브러리로 실행되며 별도의 분류 패키지 설치가 필요 없습니다.

## 분류 및 평가 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python classify_wind.py
```

주요 처리 내용은 다음과 같습니다.

- `target_time`을 기준으로 2023년 1월부터 2024년 11월까지 학습
- 2024년 12월 1~31일을 평가
- 실제 풍속이 4.0 m/s 이상이면 정답을 1, 미만이면 0으로 설정
- 입력 특성은 `wind_speed_ms`, `temperature_C`, `humidity_pct`, `wind_speed_1h_before_ms`, `wind_speed_2h_before_ms`
- 학습 자료로 표준화 기준을 계산하고 평가 자료에는 같은 기준을 적용
- 로지스틱 회귀는 클래스 가중치 없이 학습
- 강풍 확률은 `predict_proba`의 강풍(1) 확률을 사용
- 0.50 이상 또는 0.20 이상인 경우 각각 강풍으로 판정

주요 결과는 다음과 같습니다.

- 학습: 전체 16720행, 0 = 15427개, 1 = 1293개
- 평가: 전체 744행, 0 = 705개, 1 = 39개
- 생성 파일: `classification_predictions.csv`
- 생성 파일: `classification_scores.csv`
- 첫 평가 행의 강풍 확률은 약 `0.013751`

평가 방법별 주요 지표:

| 방법 | TP | FN | FP | TN | 정확도 | 강풍 정밀도 | 강풍 재현율 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 항상 0 | 0 | 39 | 0 | 705 | 0.947581 | 해당 없음 | 0.000000 |
| 현재 상태 유지 | 9 | 30 | 30 | 675 | 0.919355 | 0.230769 | 0.230769 |
| 로지스틱 회귀 0.50 | 4 | 35 | 6 | 699 | 0.944892 | 0.400000 | 0.102564 |
| 로지스틱 회귀 0.20 | 15 | 24 | 41 | 664 | 0.912634 | 0.267857 | 0.384615 |

## 그래프 실행

분류 CSV가 생성된 상태에서 다음 명령을 실행합니다.

```powershell
python plot_strong_wind.py
```

이 스크립트는 `classification_predictions.csv`에서 다음 조건의 행을 사용합니다.

- 정답 시각: 2024년 12월 1일 00:00부터 12월 7일 23:00까지
- 시간순 정렬
- 위쪽 그래프: 실제 풍속과 4.0 m/s 기준선
- 아래쪽 그래프: 실제 강풍, 로지스틱 회귀 0.50 판정, 로지스틱 회귀 0.20 판정
- 값이 1인 시각에만 각 점을 표시
- 위아래 그래프는 같은 정답 시각 축을 공유

주요 결과는 다음과 같습니다.

- 사용한 행 수: 168행
- 저장 파일: `strong_wind_december.png`
- 12월 2일의 0.50 판정 틀린 사례:
  - 정답 시각: `2024-12-02 15:00:00`
  - 실제 풍속: `4.0 m/s`
  - 강풍 확률: `0.022767`
  - 실제 정답: `1`
  - 0.50 예측값: `0`
